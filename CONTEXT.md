# Project Context

## Overview
This repository contains the source code for a website built for a political government simulator. The website is centered around a fictional election: the **2064 General elections of Caprica**.

## Subject
The website represents the **Social Democratic Alliance (SDA)** and is **Rejuvenation focused** (instead of the previously planned "The Left" alliance). 

## Design & Aesthetics
- **Main Theme Color:** `#B50000` (Red) - *Unless specified otherwise following the shift in focus.*
- **Aesthetic Guidelines:** The design should be slightly minimal but with its own unique characteristics, avoiding being "overly done." It must remain premium, modern, and use sharp, structured borders (minimal to no border radius) to give a serious political tone.
- **No Generative AI images** (except SVGs).

## Assets
The following logo assets are provided in the workspace:

*(Note: The focus is now on SDA and Rejuvenation).*

## Tech Stack
- Vanilla HTML, CSS, and JS (No Vite/React).
- Prioritize semantic HTML and SEO best practices.
