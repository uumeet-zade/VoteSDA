# Project Context

## Overview
This repository contains the source code for a website built for a political government simulator. The website is centered around a fictional election: the **2068 General elections of Caprica**.

## Subject
The website represents the **Social Democratic Alliance (SDA)**. 

## Design & Aesthetics
- **Main Theme Color:** `#B50000` (Red) or `#D7003A`.
- **Aesthetic Guidelines:** The design should be premium, modern, and minimalist with its own unique characteristics. We will implement both Light Mode and Dark Mode. Use sharp, structured borders (minimal to no border radius) to give a serious political tone.
- **No Generative AI images** (except SVGs).

## Assets
The following logo assets are provided in the workspace:
- `ALiconnew.png`
- `SDAlogo.svg`
- `SDAsmall.svg`
- `Theleft.png`

*(Note: The focus is strictly on SDA).*

## Tech Stack
- Vanilla HTML, CSS, and JS (No Vite/React).
- Prioritize semantic HTML and SEO best practices.
